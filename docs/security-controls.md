# Security controls and observed results

**Evidence dates:** 25 and 26 September 2026. These are manual observations from the AWS CLI, `kubectl`, Terraform and the application demo. They are **not** Security Hub CSPM findings or a claim of full CIS compliance. The raw audit file lives in ignored `evidence/private/security-audit.txt`; redact account IDs, ARNs, operator IPs and submitted contact details before sharing. The first audit showed `null` for EKS endpoint settings because it queried `vpcConfig`; a separate corrected `resourcesVpcConfig` query confirmed the actual settings, and `scripts/security-audit.sh` now uses that field. Repeat Ansible deployment reported `changed=0`, `failed=0`; a fresh Terraform plan on 26 September reported `No changes`, with one Ready worker, two available Flask Pods and ALB readiness HTTP 200.

RDS reports `MultiAZ=false`. | One worker, one NAT gateway and single-AZ RDS are demo cost tradeoffs and single points of failure. No claim of cross-AZ workload availability. |
